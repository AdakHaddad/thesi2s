\section{Kode Testbench}

Testbench berikut digunakan untuk memverifikasi transaksi AXI4-Lite, konfigurasi
register IP I2S, serta keluaran clock dan sinyal audio I2S. Testbench bersifat
\textit{self-checking} dan mencatat jumlah kesalahan selama simulasi.

    language=Verilog,

    breaklines=true,

Seluruh kode sumber RTL dan firmware yang dijelaskan pada Bab~IV, beserta dokumentasi proyek, berkas Vivado, dan skrip pendukung, tersedia secara terbuka pada repositori GitHub: \url{https://github.com/AdakHaddad/thesi2s}. Repositori tersebut mencakup implementasi IP I2S Transmitter berbasis AXI4-Lite untuk MicroBlaze V, firmware pengujian, berkas konfigurasi Vivado, skrip rekonstruksi proyek, serta dokumentasi tambahan yang digunakan selama pengembangan dan validasi sistem.

Pengelolaan repositori menggunakan \textit{Hog (HDL on Git)}, yaitu kerangka kerja berbasis Git untuk mendukung reproduksibilitas proyek FPGA dan rekonstruksi proyek AMD Vivado.
