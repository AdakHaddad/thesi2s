\hspace{1cm}Audio plays an essential role in modern electronic devices, ranging from entertainment systems to communication equipment. To transmit digital audio data between electronic components, the \textit{Inter-IC Sound} (I2S) protocol is widely employed for communication between processors or microcontrollers and digital audio devices such as \textit{Digital-to-Analog Converters} (DACs). In FPGA (\textit{Field-Programmable Gate Array})-based systems, commercially available audio Intellectual Property (IP) cores are often proprietary or vendor-dependent, limiting design flexibility and portability. Therefore, developing an independent I2S transmitter IP core using a hardware description language provides a flexible and reusable solution for FPGA-based embedded audio systems.

\hspace{1cm}This research aims to design and implement an AXI4-Lite-based I2S transmitter IP core using Verilog HDL for integration into a \textit{System-on-Chip} (SoC) built around the MicroBlaze~V processor on the Basys3 FPGA platform. The main contribution of this work is the development of an I2S transmitter IP that supports arbitrary sampling frequencies through a \textit{Numerically Controlled Oscillator} (NCO) based on a phase accumulator, eliminating the need for licensed audio IP cores or dedicated clock generators for each sampling frequency.

\hspace{1cm}The proposed methodology consists of RTL design of the I2S transmitter using Verilog HDL, implementation of an AXI4-Lite register interface, integration into a MicroBlaze~V-based SoC using AMD Vivado, development of bare-metal software in AMD Vitis for register configuration and audio sample transmission, and verification through RTL simulation, oscilloscope measurements, and hardware validation using a PCM5102A DAC module.

\hspace{1cm}The results demonstrate that the proposed I2S transmitter IP was successfully integrated into the MicroBlaze~V-based SoC and controlled through the AXI4-Lite interface. The system correctly generated the BCLK, WS, and DATA signals in accordance with the Philips I2S specification, transmitted stereo audio samples reliably, and supported both standard and arbitrary sampling frequencies using a single reference clock through the phase accumulator architecture. Hardware implementation on the Basys3 FPGA utilized \textbf{903 slices}, \textbf{2435 LUTs}, \textbf{2330 flip-flops}, and \textbf{32 BRAMs}, with an estimated total on-chip power consumption of \textbf{0.209~W}. Furthermore, the implemented design successfully met all timing constraints for the target \textbf{100~MHz} system clock, demonstrating that the proposed IP core provides a resource-efficient, timing-compliant, and flexible solution for FPGA-based digital audio applications.
