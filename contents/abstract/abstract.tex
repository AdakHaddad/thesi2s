\noindent
Audio plays an essential role in modern electronic systems, ranging from multimedia applications to communication devices. Digital audio transmission between electronic components commonly relies on the Inter-IC Sound (I2S) protocol, which provides a standardized interface between processors or microcontrollers and audio devices such as Digital-to-Analog Converters (DACs). In FPGA-based systems, commercially available audio Intellectual Property (IP) cores often require proprietary licenses or depend on vendor-specific implementations, limiting design flexibility. Therefore, developing an independent I2S transmitter peripheral using a hardware description language provides a practical solution for FPGA-based embedded systems requiring digital audio output without relying on third-party proprietary IP.

This research aims to design and implement a custom AXI4-Lite-based I2S transmitter IP core using Verilog HDL for integration into a MicroBlaze V-based System-on-Chip (SoC) on the Basys3 FPGA platform. The proposed IP is configurable through memory-mapped registers and controlled by software running on Xilinx Vitis. The main contribution of this work is the development of an I2S transmitter IP supporting arbitrary sampling frequencies through a Numerically Controlled Oscillator (NCO) based on a phase accumulator, enabling flexible sampling-rate generation without requiring proprietary audio IP while being validated on real hardware using a PCM5102A DAC module.

The research methodology consists of five stages: (1) designing the Verilog RTL of the I2S transmitter according to the Philips I2S specification for stereo audio transmission; (2) implementing an AXI4-Lite register interface for configuration, sample loading, and status monitoring; (3) integrating the custom IP into a MicroBlaze V-based SoC using Vivado IP Integrator; (4) developing bare-metal software in C using Xilinx Vitis for register configuration, DDS-based sinusoidal sample generation, and audio sample transmission through memory-mapped I/O; and (5) validating the design through RTL simulation, oscilloscope measurements, and hardware testing with the PCM5102A DAC module.

The experimental results demonstrate that the proposed I2S transmitter IP was successfully integrated into the MicroBlaze V-based SoC and operated correctly through the AXI4-Lite interface. The system generated valid Philips I2S signals, transmitted stereo audio samples correctly, and supported programmable standard and arbitrary sampling frequencies using a single reference clock through the NCO architecture. Hardware validation confirmed that the proposed design operated according to specification on the target FPGA platform, demonstrating its suitability as a flexible and reusable digital audio output peripheral for future FPGA-based embedded systems.

\textbf{Keywords}: MicroBlaze V, I2S, Verilog HDL, AXI4-Lite, FPGA, System-on-Chip, PCM5102A, Digital Audio.
