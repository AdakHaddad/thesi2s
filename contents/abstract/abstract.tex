\hspace{1cm}\textit{Audio plays an essential role in modern electronic devices, ranging from entertainment systems to communication equipment. To transmit digital audio data between electronic components, the Inter-IC Sound (I2S) protocol is widely employed for communication between processors or microcontrollers and digital audio devices such as Digital-to-Analog Converters (DACs). In Field-Programmable Gate Array (FPGA)-based systems, commercially available audio Intellectual Property (IP) cores are often proprietary or vendor-dependent, limiting design flexibility and portability. Therefore, developing an independent I2S transmitter IP core using a hardware description language provides a flexible and reusable solution for FPGA-based embedded audio systems.}

\par\vspace{0.8em}

\hspace{1cm}\textit{This research aims to design and implement an AXI4-Lite-based I2S transmitter IP core using Verilog HDL for integration into a System-on-Chip (SoC) built around the MicroBlaze~V processor on the Basys3 FPGA platform. The main contribution of this work is the development of an I2S transmitter IP that supports programmable integer sampling rates within the RTL operating range through a Numerically Controlled Oscillator (NCO) based on a phase accumulator, eliminating the need for licensed audio IP cores or dedicated clock generators for each sampling rate.}

\par\vspace{0.8em}

\hspace{1cm}\textit{The proposed methodology consists of RTL design of the I2S transmitter using Verilog HDL, implementation of an AXI4-Lite register interface, integration into a MicroBlaze~V-based SoC using AMD Vivado, development of bare-metal software in AMD Vitis for register configuration and audio sample transmission, and verification through RTL simulation, oscilloscope measurements, and hardware validation using a PCM5102A DAC module.}

\par\vspace{0.8em}

\hspace{1cm}\textit{The results demonstrate that the proposed I2S transmitter IP was successfully integrated into the MicroBlaze~V-based SoC and controlled through the AXI4-Lite interface. The system correctly generated the BCLK, WS, and DATA signals in accordance with the Philips I2S specification, transmitted stereo audio samples reliably, and supported standard and non-standard integer sampling rates within the RTL operating range using a single reference clock. The implemented SoC used 903 slices, 2,435 LUTs, 2,330 flip-flops, and 32 BRAMs on the Basys3 FPGA, with an estimated total on-chip power consumption of 0.209~W. The timing report showed a WNS of 0.064~ns at 100~MHz, corresponding to an estimated maximum operating frequency of approximately 100.64~MHz.}
\par\vspace{0.8em}

\noindent\textit{\textbf{Keywords}: FPGA, Verilog HDL, Inter-IC Sound (I2S), AXI4-Lite, MicroBlaze~V, System-on-Chip (SoC), PCM5102A, Digital Audio.}
